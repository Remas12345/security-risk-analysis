# security-risk-analysis

##  Enterprise IT Security Assessment & Risk Analysis

This project simulates a real-world enterprise security assessment scenario.

---

## Overview
Identified and prioritized critical security risks within a telecom-scale IT infrastructure, focusing on vulnerability assessment, risk analysis, and mitigation planning.

This assessment highlights risks that may impact system availability, data confidentiality, and operational continuity.

---

## Key Findings
- Critical: Unpatched legacy systems exposing infrastructure to high risk  
- High: SQL injection vulnerabilities risking sensitive data exposure  
- Medium: Insider misuse of privileged access  
- Medium: Third-party security risks  

---

## Risk Analysis
Developed a risk prioritization model based on impact and likelihood to support decision-making and risk mitigation planning.

---

## Recommendations
- Replace unsupported legacy systems  
- Strengthen authentication policies (MFA)  
- Conduct regular vulnerability assessments  
- Implement Data Loss Prevention (DLP) solutions  
- Improve third-party risk management  

---

## Frameworks
ISO 27001 | NIST CSF | Saudi NCA | PDPL  

---

## Note
This project is an academic case study simulating a real-world enterprise IT security assessment, including vulnerability analysis, risk prioritization, and mitigation planning.
